TrackYourCash

Self-hosted personal finance for friends and family.

An invite-only budgeting and net-worth app where every person gets their own private household. Bank accounts sync automatically each night, transactions are categorized by rules, merchant memory and opt-in AI, and a full set of reports shows where the money goes. It also works as a Claude connector over MCP, so a household can ask questions about its own finances in plain English.

Open cash.jekapps.com ↗
  • Automatic bank sync with encrypted credentials, retries and failure alerts
  • Budgets, recurring-bill detection, savings goals, debt payoff and investments
  • Cash-flow Sankey, spending breakdowns and net-worth history
  • OAuth-secured MCP server with read-only or audited write access per household
  • Tenant isolation enforced twice: EF Core query filters and Postgres row-level security

1Poker

A private poker tracker and study tool.

A native iOS app for live poker players. Track cash games and tournaments as you play, record hands on a visual table and replay them street by street, and see where your results really come from. Everything stays on the device: no account, no ads, no analytics and no third-party code.

Get it on the App Store ↗ 1poker.app ↗
  • Live session tracking with stack charts, rebuys, add-ons and hourly rate
  • Hand recorder and replayer for Hold'em and the Omaha family
  • Monte Carlo equity, pot-odds and ICM calculators
  • On-device AI hand parser built on Apple's Foundation Models
  • Optional iCloud sync to the user's own private database, plus CSV import/export
  • Swift
  • SwiftUI

Prediction Market Trading System

Automated, event-driven trading on prediction markets.

A fully automated trading system that watches prediction markets in real time and acts within milliseconds when it finds a pricing inefficiency. It runs unattended in Docker on Azure, with live order-book streams, an execution engine built around safety checks and a monitoring stack to keep an eye on it all. The venues and strategy stay private, but the engineering is the fun part.

Source code is private.

  • Asynchronous, event-driven core reacting to WebSocket market-data streams
  • LLM-assisted market analysis layered on fast deterministic heuristics
  • Execution engine with position tracking, guard rails and a dedicated safety test suite
  • Redis for caching and pub/sub, PostgreSQL for history, FastAPI for control
  • Prometheus and Grafana for live monitoring
